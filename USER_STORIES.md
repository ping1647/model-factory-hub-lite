# User Stories

## US-001 Dashboard overview
As an investor, I want to see a quick overview of model health and buy-zone attention items so I know what to review first.

## US-002 Model registry
As an investor, I want to search and filter M1-M16 by readiness/status so I know which models can support decisions.

## US-003 Watchlist
As an investor, I want to view tickers mapped to models and themes so I can connect stock ideas to the right model.

## US-004 Buy zone monitor
As an investor, I want to see Near Buy Zone, Wait, Hold, Speculative, and Avoid Chase labels so I can avoid emotional buying.

## US-005 Batch log
As an investor, I want to see recent model development batches so I know what improved and what is still missing.

## US-006 Agent workflow
As a product owner, I want PM/BA/Dev/PQA roles and task states so AI work does not become messy.

## US-007 QA checklist
As a product owner, I want test cases for every key flow so the app does not crash after changes.
