# Acceptance Criteria

## MVP acceptance
- App loads from `index.html` without build step.
- Sidebar navigation opens all pages.
- Dashboard cards render without API calls.
- Model Registry search/filter works.
- Watchlist search/filter works.
- Buy Zone filter works.
- Clicking model/stock opens a detail modal.
- Modal closes with Close button and backdrop click.
- Empty states display friendly messages.
- App still renders if one field is null/missing.
- Mobile layout does not overflow the entire page; wide tables are horizontally scrollable.
- Settings page clearly shows Local mock data mode.

## Do not pass MVP if
- A button crashes the page.
- App requires an external API to load.
- App requires Replit credits.
- Live prices are shown without source/date.
- Buy/sell recommendations appear without current price validation.
