# API Spec

No live API in MVP.

## Future data source candidates
- Model registry JSON from GitHub
- Watchlist JSON from GitHub
- Price API provider
- Earnings calendar provider
- Batch log generated by ChatGPT/Codex process

## Future API guardrails
- Every price must include source, timestamp, currency, and market status.
- App must show stale-data warning if price is old.
- API failure must not crash UI.
- Cache should be used to prevent slow loading and rate-limit issues.
